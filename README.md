## Setup

To run this portfolio locally on your machine, follow these steps:

1. Clone this repository:

    ```bash
    git clone https://github.com/frostneek/portfolio.git
    ```

2. Navigate into the project folder:

    ```bash
    cd portfolio
    ```

3. Open the `index.html` file in a browser to view the website.

4. (Optional) If you want to enable form submission with PHP, ensure you have a server with PHP support (e.g., XAMPP, MAMP, or a live web server). You can customize the `submit_form.php` file to process form submissions.
